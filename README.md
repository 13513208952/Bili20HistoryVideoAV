# Bili20HistoryVideoAV

这是一个我借助common crawl（还有点internet archive）数据源收集的bilibili官网首页出现过的av号。出于观感考虑，我进行了一些基于标题和关键词的简单过滤，同时由于采集技术有限，可能会有一些本不该出现的av号误入。

本仓库有五个发布文件：本说明、当前可用候选 `av_list.txt`、已确认失效记录 `lost.av_list.txt`、全量历史采集记录 `global_past_av_list.md`、`EXCLUSION_RULES.md`。工程文件之类不再上传。

采集情况总的来说来自2019年和2020年的存档记录的av号数量远大于其他年份。不过根据观感来看，也是这两年比较好。
如果想要搭建自定义B站推流，这个项目的av号经过过滤和筛选，应该可以提供还可以的观感体验。
作为老av号集中收录，很大一部分视频已经失效，考虑到新浪云备份等其他项目仍然有提供恢复的可能性，我没有剔除，使用者可以自行分析处理。
本次对正式名单进行了未登录公开接口状态核验：只有明确返回 `-404`（不存在）或 `62002`（稿件不可见）的 42,658 个 AV 从 `av_list.txt` 移入 `lost.av_list.txt`；访问受限、网络失败和其它状态不明项目没有因此剔除。`lost.av_list.txt` 主要保存早期年份中已经失效、但仍可能从 **Internet Archive 对已关停的新浪云 B 站视频镜像站所保存的归档备份**中恢复的历史 AV；这里说的是同一个归档来源，不是 Internet Archive 与新浪云两个仍可访问的来源。这批条目具有较高的二次利用价值，但不能当作普通 `av_list.txt` 直接使用：客户端需要为它们单独设计归档检索、可恢复性确认、缓存、预下载、推流选择和预约名单等机制；其中仍会有大量视频无法从该归档备份恢复。
21年及以后的B站视频环境出现明显恶化，并且逐渐积累和加剧，直到今天，所以如果我发现了合适的视频也会把其av/bv号加入记录，但是我不会再专门整理和收集。
同时，还有一个来自于internet archive记录的数据的规模小得多的数据源会在后面加入，不过由于采集手段限制，可能会有后续年份甚至26年混入。
后续 Internet Archive 来源加入正式 `av_list.txt` 后，会再按当时全部现行收录规则补扫新增来源；允许影响既有名单的规则同样会移除 Archive 新增命中项。`global_past_av_list.md` 则会在现有结果之后保留 Archive 搜集到的全部 AV，不因正式筛选而删除；它是采集全集，不等于正式批准名单。
由于成本有限，很多清理和整理工作就被放弃了。如果质量不合您意-为什么不去问问神奇的大肥鱼呢？

过滤说明
剔除了明星专栏，mmd专栏，进行了屏蔽词过滤；
包括但不限于：王者荣耀，开局送，洛天依，（多个明星，不再列出），（部分古远游戏名称，这里不在列出），SAO,（多部电视剧，如逐玉，这里不再列出）...... 详情请查看对应文件。
过滤是为了改善观看体验和过滤部分群体对于整体体验的影响，同时尽力减少当年大量劣质游戏的商单视频影响。
另外一个文件会尽可能解释过滤具体规则和原因。

如果您是出于考古等目的，建议自行在common crawl和internet archive中采集真正的原始数据，我没有办法提供任何保证。

按 AV 号直接使用，例如 `av170001`。本仓库不对视频内容的可用性、版权或适宜性作任何担保；仅提供历史 AV 号清单与筛选规则说明。
