# Bili20HistoryVideoAV

本目录收录从 Common Crawl 和 Internet Archive 存档中整理出的 B 站历史 AV 号，提供筛选后的候选、失效记录和原始采集总账。它不是对视频可播放性的保证。

- `av_list.txt`：发布候选名单。保留原发布范围，移除现行筛选命中和确认失效项；未验证或无法确认的条目不因状态不明而删除。
- `lost.av_list.txt`：历史失效记录与本次验证库快照中确认失效的 AV。只有 B 站业务码 `-404` 和 `62002` 算确认失效；HTTP 错误、网络问题、风控和状态不明不新增失效记录。有更新的明确可用结果时，不再列为失效。本表也收录从未进入发布候选名单的历史 AV。
- `global_past_av_list.md`：原始历史采集总账，按原样保存，不是筛选结果或正式批准名单。
- `总排除规则.txt` 和各分类规则文档：说明排除范围与匹配口径。

外层年份子目录按视频实际投稿或发布年分组；`年份未确认/` 则按本地证据中的最早抓取年分组。两边都按来源拆分；同一 AV 同时出现在 Common Crawl 和 Archive 时，只列入 Archive。分组名单是候选池，不等同于根目录的 `av_list.txt`。

每行一个 AV 号，例如 `av170001`。失效记录不可直接当成现网推流名单；部分视频可能存在归档副本，但需另行确认。本文档和名单不保证视频可用性、版权或适宜性。
